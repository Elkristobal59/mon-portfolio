INFRASTRUCTURE — HOMELAB

Cloud Photo Privé — Immich

Déploiement d'une stack Docker sur serveur Lenovo (Proxmox Virtualization) avec stockage distant sur un NAS Synology DS218 Play, accessible depuis n'importe où via le réseau privé Tailscale (WireGuard). Sauvegarde automatique de 2 iPhones — sans ouvrir un seul port.

Docker ComposeSynology NASImmichPostgreSQL (pgvecto-rs)Redis cacheCUDA (MSI GPU)Intel QuickSyncTailscale VPNWireGuard

🎯 Vision du projet

Après des années sur Google Photos et iCloud, j'ai souhaité reprendre une souveraineté totale sur mes souvenirs. L'objectif : bâtir mon propre "Google Photos" privé, sans compromis sur l'expérience utilisateur, mais 100% auto-hébergé.

Une solution sans abonnement, accessible mondialement via VPN, et capable d'absorber des dizaines d'années de photos familiales en toute sécurité.

L'infrastructure repose sur un hyperviseur Proxmox VE (installé sur un serveur Lenovo dédié) qui héberge une machine virtuelle Debian Linux pour faire tourner la stack Docker de manière isolée et stable.

Interopérabilité Réseau : Mise en place de montages réseaux CIFS/SMB robustes sous forme de volumes Docker directement raccordés à la VM Debian (Proxmox VE) et le NAS Synology distant, permettant de déporter le stockage de la bibliothèque Immich (plus de 300 Go de souvenirs) sans surcharger le stockage local de la VM.

⚡ Optimisation : Du GPU vers le CPU

Phase Initialisation
Puissance CUDA (MSI)

Utilisation intensive d'un laptop MSI avec GPU NVIDIA pour l'indexation initiale massive. Cela a permis un traitement ultra-rapide des visages et objets (CLIP/ML) sur plus de 200 000 fichiers.

Phase Quotidienne
Architecture CPU Stable

Migration vers une architecture CPU stable (Lenovo/Debian) pour le quotidien. Cette configuration assure une consommation réduite tout en restant réactive pour les nouveaux imports.

"Immich a bénéficié de la puissance CUDA (MSI) pour l'indexation initiale massive, assurant un traitement rapide des visages et objets, avant de basculer sur une architecture stable CPU pour le quotidien."

📦 Services Déployés

📸
Immich & Machine Learning
Photo, Vidéo & IA

Alternative open-source à Google Photos. Reconnaissance faciale et d'objets propulsée par l'intelligence artificielle (Machine Learning).

🗄️
PostgreSQL & Redis
Base de données & Cache

Base de données robuste avec l'extension pgvecto-rs pour gérer efficacement la recherche vectorielle (embeddings des photos), épaulée par un broker Redis pour le système de file d'attente (traitement vidéo intensif, ML).

🔐
Tailscale (WireGuard)
VPN Mesh

Réseau privé mesh basé sur WireGuard. Chaque appareil rejoint le réseau Tailscale et accède directement au NAS sans ouvrir de port, avec chiffrement de bout en bout et MagicDNS.

💡 Apprentissages Clés

  • ✓ Tailscale (basé sur WireGuard) offre un VPN mesh plug-and-play qui sécurise l'accès distant sans aucune configuration firewall.
  • ✓ Docker Compose simplifie drastiquement la gestion des dépendances multi-services (bases de données, cache Redis, workers...).
  • ✓ La gestion des volumes Docker pour la persistance des données est critique — une mauvaise config = perte de données.
  • ✓ L'optimisation hybride (GPU pour l'init, CPU pour le run) permet de concilier performance brute et sobriété énergétique.
  • ✓ Les architectures orientées micro-services pour l'IA nécessitent un stockage optimisé pour les vecteurs (extensions comme pgvecto-rs).
